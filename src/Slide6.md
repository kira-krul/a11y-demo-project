


Random things I learned while researching this topic:
=========

* Twitter has hotkeys, like `j`/`k` for moving to the next/previous tweet or `l` to
like a tweet. As a vim user, I find it delightful, but unfortunately, it breaks the
Success Criterion [2.1.4](https://www.w3.org/WAI/WCAG22/Techniques/failures/F99)

* Some suggested techniques by WCAG are absolutely ancient, for example the
JavaScript code for this one reads like it was written by a caveman: [SCR33](https://www.w3.org/WAI/WCAG22/Techniques/client-side-script/SCR33)

* Unskippable ads are, unfortunately, allowed. The x button needs to be at least
24x24 large for AA or 44x44 for AAA but otherwise they're explicitly mentioned in
the standard and can pass all rules

* The example code for the demo was almost completely created by Claude. I never
mentioned anything about accessibility to it, so if you wondered how it much it
cares by default, you've just seen it.
